3 Предпросмотр и скачивание

Проверьте таблицу: баллы, причины отсутствия и даты можно править прямо здесь. Затем скачайте книгу Excel.

Распознать разбаловку по фото

Сфотографируйте лист с разбаловкой: строки чисел по критериям и «= общий балл», сверху подписи 1зд / 2зд / 3зд. Модель прочитает структуру заданий и лестницу баллов для каждого класса на фото. Нужен ключ Claude API — он хранится только в вашем браузере.
Платформа · Всё считается в браузере — файлы никуда не отправляются (кроме фото на распознавание, если вы сами его запустили). Баллы в таблице можно править вручную, итоги и формулы пересчитаются.
