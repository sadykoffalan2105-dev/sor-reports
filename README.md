# Отчёты СОР / СОЧ

Сайт-генератор школьных отчётов по суммативному оцениванию (СОР — за раздел, СОЧ — за четверть).
Всё работает в браузере, без сервера: файлы никуда не отправляются.

**Сайт:** https://sadykoffalan2105-dev.github.io/sor-reports/ (публикуется автоматически при push в `main`).

## Что делает

1. Принимает выгрузку журнала из emaktab.uz (`.xls` / `.xlsx`, по одному классу на файл или лист).
   Из шапки берёт класс, группу (мальчики / девочки), предмет, учителя, учебный год, четверть;
   из таблицы — учеников и колонки «СОР» / «СОЧ» (дата, максимум, баллы).
2. **Раскидывает общий балл по заданиям** по «лестнице баллов» (см. ниже) или одним из запасных
   способов: с самого тяжёлого задания, пропорционально, случайно с сидом.
3. Показывает отчёт для проверки: сводка, таблица (любой балл можно поправить руками — итоги
   пересчитаются) и диаграмма.
4. Скачивает книгу Excel по образцу школы: лист на класс, шапка с фиолетовой цифрой варианта формы,
   «Участвовали / Отсутствовали», таблица с формулами (`Общий балл`, `В%`, `Оценивание`), «Сред.балл»,
   «Процентный показатель», «Количество 5 / 4», «Эффективность знаний», подпись учителя, блок
   «Примечание» и столбчатая диаграмма (баллы по заданиям в сегментах, общий балл над столбцом).

Даты проведения и внесения в emaktab по умолчанию остаются пустыми (заполняются вручную);
дату из журнала можно подставить галочкой.

## Разбаловка заданий

Разбаловки хранятся в библиотеке пресетов («5 класс — СОР 50», «6 класс — СОР 50», …); у каждого
класса можно выбрать свою, иначе действует общая. Редактор:

- задания и критерии добавляются кнопками, у каждого — баллы и необязательное название для шапки
  («Практическая работа», «Чертёж» …);
- быстрый ввод текстом: `5; 5+5+20+10; 5` (задания через `;`, критерии через `+`, подкритерии в скобках: `5; 5+(3+2)+20; 5`);
- «критерий в критерии»: кнопка «＋ под» делит критерий на подкритерии любой глубины, шапка строится из дерева (`src/core/header.ts`) одинаково для предпросмотра и Excel;
- панель «Шапка таблицы»: стиль подписи задания, нумерация критериев, уровни-диапазоны под критериями (общие и для отдельного критерия), колонки отсутствия;
- **распознавание по фото**: кнопка «📷 Распознать по фото» отправляет снимок рукописной
  разбаловки в Claude API (нужен ключ, он хранится только в браузере) и возвращает структуру заданий
  и лестницу баллов для каждого класса на листе; результат можно проверить и применить как пресет.

## СОР и СОЧ

Программа сама находит в журнале колонки СОР и СОЧ: в карточке класса видно «В журнале: СОР ✓ 07.10 · макс 50 · СОЧ ✓ 23.10 · макс 40»
(или «СОЧ — нет в журнале» / «без баллов»). Журнал с обеими колонками даёт две записи класса — у каждой своя колонка, разбаловка
(для СОЧ подбирается разбаловка на 40) и свои введённые баллы. В настройках «Какой отчёт делать»: СОР, СОЧ или СОР и СОЧ
(тогда в книге два листа на класс: «5с СОР» и «5с СОЧ»).

## Два режима

- **📊 Раскидка по журналу** — общий балл из выгрузки emaktab раскладывается по заданиям (лестница, правило снятия, цели).
- **🎤 Бумажные работы** — общий балл каждого ученика берётся из загруженного журнала (колонка СОР/СОЧ), критерии
  сначала разложены по раскладке (серым курсивом); баллы по критериям с бумаги диктуются голосом или вводятся с клавиатуры
  (Enter — следующая клетка). Если сумма критериев не совпала с баллом журнала — строка подсвечивается красным,
  перед скачиванием программа предупреждает. Ученики без балла в журнале остаются пустыми для ввода.

## Голосовой ввод

Кнопка «🎤 Голосовой ввод». Говорите **фамилию и баллы по критериям**: «Алимбаев пять пять пять десять десять
пятнадцать». Без фамилии баллы идут текущему ученику (жёлтая строка), после полной строки — следующий
невведённый. Можно частями. Одно число больше максимума первого критерия — общий балл (разложится по раскладке);
явно: «общий сорок шесть». Команды: «дальше», «назад», «номер пять», «Цой отсутствует», «все на максимум»,
«исправь четыре восемнадцать», «сначала», «отмена», «повтори», «следующий класс», «скачать», «печать», «стоп».

- **Офлайн-распознавание (по умолчанию)** — модель Vosk (vosk-model-small-ru-0.22, Apache 2.0) работает прямо
  в браузере через WebAssembly: любой современный браузер и exe-приложение, без интернета. Модель 46 МБ
  скачивается один раз и хранится в браузере. При сборке её скачивает GitHub Actions — в репозитории её нет.
- **Браузерное** — Web Speech API (Chrome / Edge / Яндекс / Safari), онлайн.
- Фамилии сравниваются **по звучанию** (латиница ↔ кириллица, «олимп баев» → Алимбаев). Если фамилия
  прозвучала, но не узнана, **балл не записывается** чужому ученику. Балл больше максимума критерия — тоже.
- Проверено на русской речи (голос Windows «Irina»): 8 фраз распознаны, отклик 0,3–0,9 с после фразы.
- Для класса без журнала: «Ввести список вручную» → «🎤 Диктовать список».

## Готовые отчёты

В ту же область загрузки можно бросить **готовую книгу** (сделанную этим сайтом или школьную форму с той же
шапкой): каждый лист станет классом, шапка — разбаловкой (названия заданий, критерии, уровни), баллы — баллами
учеников. Потом можно добавить другие классы и скачать общую книгу.

## Приложение

- **Установить** (кнопка в шапке, Chrome / Edge / Android) — сайт работает как приложение, в том числе без сети.
- **Для Windows (exe)** — в [Releases](https://github.com/sadykoffalan2105-dev/sor-reports/releases/latest):
  portable (без установки) и setup. Собирается GitHub Actions (`.github/workflows/app.yml`, Electron).

## Лестница баллов

Общий балл ученика раскладывается по заданиям по «лестнице»: таблица «балл → раскладка»,
которую программа строит по правилу учителя и которую можно править в самом приложении
(правки хранятся в браузере и привязаны к записи разбаловки):

1. крупные критерии снижаются по одному баллу — самый большой первым, при равных максимумах
   правый раньше левого — до 5 баллов (для критериев ≤ 10) или до 70 % (для больших);
2. затем те же критерии опускаются до половины;
3. в конце всё уходит в ноль.

Правило воспроизводит рукописные образцы для 5-го (`5; 5+5+20+10; 5`), 6-го (`5; 2+7+7+7+7+5+5; 5`)
и 7-го (`5; 2+3+7+7+7+9+5; 5`) классов — проверяется в `test/run.ts`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # статика в dist/ — деплой на GitHub Pages через .github/workflows/pages.yml
node test/run.ts   # прогон ядра на samples/*.xls → .out/*.xlsx (+ сверка лестниц с образцами)
node test/vision.ts  # нормализация ответа распознавания; живой вызов — при ANTHROPIC_API_KEY
node test/voice.ts   # разбор голосовых фраз (в т.ч. реальные результаты распознавания)
python scripts/make-icons.py  # иконки приложения
```

## Структура

- `src/parse/journal.ts` — разбор выгрузки журнала, простых списков и ручного ввода
- `src/core/structure.ts` — разбаловка: разбор/запись, заголовки колонок, пресеты
- `src/core/ladder.ts` — лестница баллов по правилу учителя, проверка
- `src/core/distribute.ts` — запасные способы распределения, оценка по порогам
- `src/core/report.ts` — модель отчёта (заголовок, строки, итоги)
- `src/export/xlsx.ts` — книга Excel (ExcelJS: стили, объединения, формулы)
- `src/export/chart.ts` — диаграмма и фигуры (цифра варианта, примечание), которые ExcelJS не умеет: дописываются в zip-архив xlsx
- `src/vision/` — распознавание разбаловки с фото через Claude API (`@anthropic-ai/sdk`, structured outputs)
- `src/voice/` — голосовой ввод: движки (`engine.ts`: офлайн Vosk и браузерный), разбор фраз (`parse.ts`), панель (`voice.ts`)
- `src/parse/report.ts` — чтение готовых отчётов
- `electron/` — exe-приложение; `public/sw.js`, `public/manifest.webmanifest` — установка и офлайн
- `src/main.ts` — интерфейс
