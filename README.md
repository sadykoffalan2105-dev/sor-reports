# Отчёты СОР / СОЧ

Сайт-генератор школьных отчётов по суммативному оцениванию (СОР — за раздел, СОЧ — за четверть).
Всё работает в браузере, без сервера: файлы никуда не отправляются.

## Что делает

1. Принимает выгрузку журнала из emaktab.uz (`.xls` / `.xlsx`, по одному классу на файл или лист).
   Из шапки берёт класс, группу (мальчики / девочки), предмет, учителя, учебный год, четверть;
   из таблицы — учеников и колонки «СОР» / «СОЧ» (дата, максимум, баллы).
2. **Раскидывает общий балл по заданиям** согласно разбаловке (например `5; 5+5+20+10; 5`):
   - *как в образце* — мелкие задания выполнены полностью, недобор снимается с самого тяжёлого подзадания;
   - пропорционально весу заданий;
   - случайно, с сидом (кнопка «Перераспределить»).
3. Показывает отчёт для проверки; любой балл можно поправить руками — итоги пересчитаются.
4. Скачивает книгу Excel по образцу школы: лист на класс, шапка, «Участвовали / Отсутствовали»,
   таблица с формулами (`Общий балл`, `В%`, `Оценивание`), «Сред.балл», «Процентный показатель»,
   «Количество 5 / 4», «Эффективность знаний», подпись учителя и столбчатая диаграмма.

Даты проведения и внесения в emaktab по умолчанию остаются пустыми (заполняются вручную);
дату из журнала можно подставить галочкой.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статика в dist/ — можно выложить на GitHub Pages
node test/run.ts # прогон ядра на samples/*.xls → .out/*.xlsx
```

## Структура

- `src/parse/journal.ts` — разбор выгрузки журнала, простых списков и ручного ввода
- `src/core/distribute.ts` — распределение баллов по заданиям, оценка по порогам
- `src/core/report.ts` — модель отчёта (заголовок, строки, итоги)
- `src/export/xlsx.ts` — книга Excel (ExcelJS: стили, объединения, формулы)
- `src/export/chart.ts` — диаграмма, которую ExcelJS не умеет: дописывается в zip-архив xlsx
- `src/main.ts` — интерфейс
